Ниже приведены ответы на контрольные вопросы, составленные строго по порядку и в соответствии с главой «Отчеты» вашего пособия.

1) Как использовать в отчете данные нескольких таблиц?

Чтобы объединить данные из нескольких таблиц, в схему компоновки данных добавляется несколько наборов данных. Затем на вкладке «Связи наборов данных» нужно описать связи между ними. При необходимости также можно создавать вычисляемые поля, чтобы объединить данные из разных наборов в одном поле.

2) Как использовать группировки в структуре отчета?

Группировки служат для упорядочивания и агрегации данных. На вкладке «Настройки» в дереве отчета, щелкнув правой кнопкой мыши по корневому элементу, можно добавить новую группировку. После этого выбирается поле, по которому нужно сгруппировать данные, например «Контрагент» или «Месяц».

3) Как получить последние значения регистра сведений?

В запросе, который является источником данных, следует использовать виртуальную таблицу СрезПоследних. Она автоматически возвращает для каждой комбинации измерений значение ресурсов, актуальное на указанную дату или момент времени.

4) Как вывести в отчет иерархические данные?

Нужно включить в запрос все необходимые поля для построения иерархии (например, «Ссылка» и «Родитель»). Затем в схеме компоновки данных на вкладке «Настройки» создать группировку с типом «Иерархия». Система сама выстроит данные в древовидную структуру на основе связей между элементами.

5) Как управлять выводом итогов по группировкам?

Итоги (ресурсы) настраиваются на вкладке «Ресурсы» схемы компоновки данных. Для каждого ресурса можно задать выражение агрегации (Сумма, Количество, Максимум и т.д.), а на вкладке «Настройки» — указать, в итогах каких группировок их выводить.

6) Как создать отчет, содержащий диаграмму?

При создании нового отчета в конструкторе настроек нужно выбрать тип «Диаграмма». После этого в структуру отчета добавляются элементы для задания рядов (Series), точек (Points) и значений. Поля для диаграммы выбираются из доступных полей набора данных.

7) Как использовать параметры в системе компоновки данных?

Параметры определяются на вкладке «Параметры» схемы компоновки данных. Они используются для передачи в отчет внешних условий (например, даты начала и конца периода) и могут быть доступны пользователю для изменения в форме отчета.

8) Что такое ресурсы в системе компоновки данных?

Ресурсы — это поля с числовыми или другими данными, по которым необходимо подсчитать итоги. Например, «Сумма», «Количество». Для каждого ресурса задается агрегирующая функция (Сумма, Среднее, Максимум и т.д.), а его значение вычисляется для записей внутри группировки.

9) Что такое вычисляемые поля в системе компоновки данных?

Это специальные поля, значения которых не берутся напрямую из набора данных, а вычисляются по формуле на основе других полей схемы на этапе компоновки отчета. Они создаются на вкладке «Вычисляемые поля».

10) Как дополнить данные отчета всеми датами в группировке по периоду?

Это делается в настройках группировки. В дереве структуры отчета нужно выделить группировку по периоду, затем на панели свойств найти свойство «Дополнять периодами» и установить его в значение Авто или вручную задать начальную и конечную даты. Это гарантирует, что в отчете будут отображаться все даты из указанного диапазона.

11) Как создать пользовательские настройки отчета?

Пользовательские настройки создаются автоматически при первом открытии отчета, а разработчик может определить их состав в схеме. На вкладке «Настройки» для каждого элемента отчета (группировки, отбора, поля) можно установить флажки «Включить в пользовательские настройки» или «Включить в быстрые настройки» и задать режим редактирования.

12) В чем отличие «быстрых» настроек от остальных?

Быстрые настройки отображаются непосредственно на форме отчета в виде отдельных полей ввода и предназначены для оперативного управления ключевыми параметрами отчета. Остальные пользовательские настройки открываются в отдельном окне «Настройки» и позволяют гибко менять структуру, отборы и оформление отчета, но требуют большего количества действий.

13) Как вывести данные в виде таблицы?

При создании отчета в конструкторе выбирается тип «Таблица». После этого в структуру отчета добавляются группировки строк и колонок, а в качестве области значений указывается ресурс. Это позволяет строить отчеты типа «шахматка», где строки и колонки динамически формируются данными.

14) Как сделать отчет универсальным?

Универсальность достигается за счет гибкой настройки встроенных механизмов платформы. Нужно использовать систему компоновки данных, чтобы вынести все ключевые параметры (отборы, сортировки, группировки) в пользовательские настройки. Это позволит менять внешний вид и содержание отчета без вмешательства в код. Ещё один подход — программное формирование схемы компоновки данных под конкретный источник.
