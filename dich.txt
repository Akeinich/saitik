
Перечисления

(стр. 279–291)

1. Для чего предназначен объект конфигурации «Перечисление»?
      Перечисление – это объект метаданных, который хранит набор постоянных, неизменяемых в процессе работы системы значений. Оно используется для ограничения списка допустимых вариантов (например, вид номенклатуры: Материал, Услуга; тип контрагента; статус документа). Пользователь может только выбрать одно из предопределенных значений, но не может изменить их состав в пользовательском режиме.
2. Как создать новое перечисление?
   · В конфигураторе открыть ветвь «Перечисления».
   · Нажать правую кнопку мыши и выбрать «Добавить».
   · Ввести имя (например, ВидыНоменклатуры). При необходимости задать синоним.
   · На закладке «Данные» перечислить все возможные значения (например, Материал, Услуга), добавляя их кнопкой «Добавить».
3. Как с помощью перечисления задать принадлежность элементов справочника к той или иной смысловой группе?
      Необходимо у справочника создать новый реквизит с типом, соответствующим созданному перечислению. Например, у справочника Номенклатура добавить реквизит ВидНоменклатуры типа ПеречислениеСсылка.ВидыНоменклатуры. Затем, заполняя элементы справочника, пользователь в карточке номенклатуры указывает конкретное значение этого реквизита – тем самым относит элемент к группе «Материал» или «Услуга».
4. Как обратиться к значению перечисления средствами встроенного языка?
      Через имя перечисления и его значение, используя точку:
   ```1c
   Перечисления.ВидыНоменклатуры.Материал
   ```
   Если требуется получить текущее значение реквизита некоторого объекта:
   ```1c
   Если Номенклатура.ВидНоменклатуры = Перечисления.ВидыНоменклатуры.Услуга Тогда
       // действия
   КонецЕсли;
   ```
5. Как задать произвольное представление объекта конфигурации?
      В свойствах объекта конфигурации на закладке «Представление» можно задать:
   · «Представление объекта» – как объект будет отображаться в единственном числе,
   · «Расширенное представление объекта» – более развёрнутое описание,
   · «Представление списка» – как будет называться список объектов.
        Также можно настроить синоним в поле «Синоним» на основной закладке – это основное имя, видимое пользователю.

Проведение документа по нескольким регистрам

(стр. 293–310)

1. Для чего может понадобиться проведение документа по нескольким регистрам?
      Хозяйственная операция часто отражается в разных разрезах учёта одновременно. Документ приходной накладной должен делать записи в регистр остатков материалов (приход) и в регистр стоимости материалов (для учёта затрат), а документ оказания услуги – списывать материал по остаткам, формировать стоимость списанного и фиксировать обороты продаж в нескольких разрезах (номенклатура, клиент, мастер). Один документ формирует движения сразу по нескольким регистрам, что обеспечивает целостность данных.
2. Как создать движения документа по нескольким регистрам в обработчике проведения документа?
      В модуле объекта документа (обработчик ОбработкаПроведения) используют конструктор движений. При открытии конструктора можно отметить «птичками» несколько регистров, в которых необходимо сформировать движения. Для каждого отмеченного регистра конструктор генерирует фрагмент кода по созданию соответствующего набора записей. Программист заполняет наборы записей для каждого регистра данными из документа и вызывает метод Записать().
3. Как создать движения документа без использования конструктора движений?
      Вручную объявить переменные, создать объекты наборов записей регистров:
   ```1c
   Движения.ОстаткиМатериалов.Записывать = Истина;
   Движения.СтоимостьМатериалов.Записывать = Истина;
   НаборЗаписейОстатки = Движения.ОстаткиМатериалов;
   НаборЗаписейСтоимость = Движения.СтоимостьМатериалов;
   ```
   Затем для каждого набора в цикле заполнить записи, указывая измерения и ресурсы, и записать оба набора (можно вызвать НаборЗаписейОстатки.Записать(); и т.д.) или положиться на автоматическое выполнение после обработчика.
4. Как средствами встроенного языка сформировать и записать движения документа в регистр накопления?
   ```1c
   // Получаем набор записей нужного регистра
   НаборЗаписей = Движения.ОстаткиМатериалов;
   НаборЗаписей.Очистить();
   Для Каждого СтрокаТЧ Из ПереченьНоменклатуры Цикл
       Если СтрокаТЧ.Номенклатура.ВидНоменклатуры = Перечисления.ВидыНоменклатуры.Материал Тогда
           Запись = НаборЗаписей.Добавить();
           Запись.ВидДвижения = ВидДвиженияНакопления.Расход; // или Приход
           Запись.Период = Дата;
           Запись.Материал = СтрокаТЧ.Номенклатура;
           Запись.Количество = СтрокаТЧ.Количество;
       КонецЕсли;
   КонецЦикла;
   НаборЗаписей.Записать();
   ```
   Аналогично формируется набор для другого регистра.
5. Как добавить в форму документа новый реквизит?
      Сначала необходимо добавить сам реквизит в метаданных объекта (документа или табличной части). Затем открыть форму документа, открыть палитру «Элементы» и перетащить реквизит из дерева реквизитов формы на нужное место в структуре формы. После этого можно настроить свойства элемента (расположение, шрифт, видимость).

Оборотные регистры накопления

(стр. 311–321)

1. Что такое оборотный регистр накопления?
      Это объект конфигурации, предназначенный для хранения исключительно оборотов (количественных и/или суммовых изменений) за определенный период. В нём не фиксируются начальные и конечные остатки, а только приход, расход или однокомпонентные обороты. Используется для анализа динамики показателей (например, продажи за месяц).
2. В чем отличие между регистром накопления остатков и оборотным регистром накопления?
   · Регистр остатков хранит состояния остатков на начало/конец периода, а также фиксирует приходные и расходные движения. По нему можно посчитать остатки на любой момент времени и оборот за период.
   · Оборотный регистр хранит только записи об оборотах (приход, расход), без остатков. Нельзя получить остаток на конкретную дату, можно только посмотреть суммы оборотов за интервал. Используется, когда важна именно динамика, а остатки не имеют смысла (например, регистр «Продажи»).
3. Как выбирать реквизиты и измерения при создании регистров накопления?
      Измерения – это аналитические разрезы, по которым в дальнейшем можно отбирать и группировать данные (например, Номенклатура, Склад, Клиент). Ресурсы – это числовые показатели, которые будут накапливаться (Количество, Сумма, Стоимость). При проектировании определяют, в каких разрезах потребуется получать отчёты, и добавляют соответствующие измерения; для числовых итогов создают ресурсы.
4. Как создать оборотный регистр накопления?
   · В дереве метаданных выбрать «Регистры накопления», добавить новый.
   · В поле «Вид регистра» выбрать «Обороты».
   · Настроить представление, определить подсистемы.
   · На закладке «Данные» добавить измерения (с типами) и ресурсы (с типами, длиной, точностью).
   · При необходимости задать реквизиты (необязательные свойства записей).
   · Сгенерировать записи в обработчиках документов, обеспечивающих формирование оборотов (например, Оказание услуги).
