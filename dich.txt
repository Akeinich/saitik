Понял, отвечаю четко по порядку на вопросы по теме «Отчеты (часть 1)».

1. Для чего предназначен объект встроенного языка «Запрос»?
      Для выполнения запросов к базе данных на языке запросов 1С и получения выборки данных.
2. Для чего предназначена система компоновки данных?
      Для гибкого формирования сложных отчетов с возможностью настройки пользователем без изменения кода.
3. Для чего предназначена схема компоновки данных?
      Для описания набора данных, связей, полей и ресурсов отчета (техническое задание для отчета).
4. Для чего предназначены настройки компоновки данных?
      Для определения структуры, отборов, сортировок, группировок и условного оформления отчета.
5. В чем отличие между реальными и виртуальными таблицами?
      Реальные таблицы физически хранятся в базе данных; виртуальные не хранятся, а формируются системой на лету при запросе.
6. Из каких частей состоит текст запроса, какие из них являются обязательными? Каковы основные синтаксические конструкции языка запросов?
      Обязательные части: ВЫБРАТЬ и ИЗ. Основные конструкции: ВЫБРАТЬ, ИЗ, ГДЕ, СГРУППИРОВАТЬ ПО, ИМЕЮЩИЕ, УПОРЯДОЧИТЬ ПО.
7. Что является источником данных запроса?
      Реальные таблицы, виртуальные таблицы, результат другого запроса, таблицы значений.
8. Что такое псевдонимы в языке запросов?
      Временные имена полей или таблиц, задаваемые через ключевое слово КАК.
9. Что такое параметры запроса?
      Переменные, передающие внешние значения в запрос (например, дату, ссылку).
10. Что такое параметры виртуальной таблицы?
       Специальные настройки виртуальной таблицы, задаваемые в скобках после её имени (например, период, условия).
11. Что такое левое соединение?
       Соединение, при котором возвращаются все записи из левой таблицы и только соответствующие из правой.
12. Что такое правое соединение?
       Соединение, при котором возвращаются все записи из правой таблицы и только соответствующие из левой.
13. Что такое полное соединение?
       Соединение, возвращающее все записи из обеих таблиц, объединяя результаты левого и правого соединений.
14. Что такое внутреннее соединение?
       Соединение, возвращающее только те записи, для которых есть соответствие в обеих таблицах.
15. Как использовать конструктор запроса?
       Вызвать контекстное меню в тексте запроса и выбрать «Конструктор запроса», затем визуально настроить таблицы, поля, связи, условия и другие параметры.
16. Как выбрать данные в некотором периоде для отчета?
       Через параметр периода виртуальной таблицы или через условие ГДЕ с оператором МЕЖДУ.
17. Как упорядочить данные в отчете?
       С помощью секции УПОРЯДОЧИТЬ ПО в запросе или метода Сортировать() у таблицы значений.
