📊 Таблица значений

1. Как создать таблицу значений?
   Используйте конструктор Новый:
   ```1c
   МояТаблица = Новый ТаблицаЗначений;
   ```
2. Как добавить колонки в таблицу значений?
   Через свойство Колонки и метод Добавить:
   ```1c
   МояТаблица.Колонки.Добавить("ИмяКолонки");
   МояТаблица.Колонки.Добавить("ИмяКолонки2", Новый ОписаниеТипов("Число"));
   ```
3. Как добавить строки в таблицу значений?
   С помощью метода Добавить(), который возвращает новую строку:
   ```1c
   НоваяСтрока = МояТаблица.Добавить();
   НоваяСтрока.ИмяКолонки = "Какое-то значение";
   ```
4. Как добавить колонку с описанием типа и заголовка?
   Метод Добавить может принимать до трех параметров: (<Имя>, <ОписаниеТипов>, <Заголовок>).
   ```1c
   ОписаниеТипаЧисло = Новый ОписаниеТипов("Число");
   МояТаблица.Колонки.Добавить("Сумма", ОписаниеТипаЧисло, "Сумма с НДС");
   ```
5. Как перечислить все строки?
   Используйте цикл "Для каждого":
   ```1c
   Для Каждого Строка Из МояТаблица Цикл
       Сообщить(Строка.ИмяКолонки);
   КонецЦикла;
   ```
6. Как перечислить все колонки?
   Аналогично, через коллекцию Колонки:
   ```1c
   Для Каждого Колонка Из МояТаблица.Колонки Цикл
       Сообщить(Колонка.Имя);
   КонецЦикла;
   ```
7. Как выгрузить колонку таблицы значений в массив?
   Используйте метод ВыгрузитьКолонку(<ИмяКолонки>):
   ```1c
   МассивЗначений = МояТаблица.ВыгрузитьКолонку("ИмяКолонки");
   ```
8. Как заполнить значения в колонке для всех строк?
   Используйте метод ЗагрузитьКолонку(<Массив>, <Колонка>):
   ```1c
   МояТаблица.ЗагрузитьКолонку(МассивЗначений, "ИмяКолонки");
   ```
9. Как посчитать итог по колонке?
   Можно использовать цикл для суммирования или применить запрос к таблице значений с итогами.
10. Как найти строку по значению?
    Для поиска одной строки используйте метод Найти(<Значение>, <ИмяКолонки>):
    1c
        НайденнаяСтрока = МояТаблица.Найти("Иванов", "Фамилия");
        
11. Как найти строки по нескольким колонкам?
    Используйте метод НайтиСтроки(<СтруктураОтбора>):
    1c
        СтруктураПоиска = Новый Структура("Имя, Город", "Анна", "Москва");
        МассивНайденныхСтрок = МояТаблица.НайтиСтроки(СтруктураПоиска);
        
12. Как искать неуникальные значения?
    Прямого метода нет, но можно реализовать, например, через вспомогательную таблицу или соответствие для подсчета.
13. Как сдвинуть строку таблицы значений?
    Используйте метод Сдвинуть(<НачальныйИндекс>, <КонечныйИндекс>) для изменения порядка строк.
14. Как создать копию таблицы значений?
    Используйте метод Скопировать():
    1c
        КопияТаблицы = МояТаблица.Скопировать();
        
15. Как скопировать таблицу значений по нужным колонкам?
    Метод Скопировать() принимает массив имен колонок для копирования.
16. Как скопировать таблицу значений по отбору?
    Метод Скопировать(<Строки>, <Колонки>) позволяет скопировать как строки, так и колонки.
17. Как свернуть таблицу значений по колонке?
    Используйте метод Свернуть(<КолонкиГруппировок>, <КолонкиАгрегатов>):
    1c
        МояТаблица.Свернуть("Фамилия", "Количество");
        
18. Как отсортировать таблицу значений по одной колонке?
    Используйте метод Сортировать(<ИмяКолонки>, <Направление>):
    1c
        МояТаблица.Сортировать("Фамилия");
        
19. Как отсортировать таблицу значений по нескольким колонкам?
    Метод Сортировать позволяет передать массив имен колонок с направлениями.
20. Как удалить строку из таблицы значений?
    Используйте метод Удалить(<Строка>) с передачей удаляемой строки в качестве параметра.

📚 Справочники

1. Как создать новый элемент справочника?
   Метод СоздатьЭлемент() у менеджера справочника:
   ```1c
   НовыйЭлемент = Справочники.Номенклатура.СоздатьЭлемент();
   НовыйЭлемент.Наименование = "Новый товар";
   НовыйЭлемент.Записать();
   ```
2. Как создать новую группу справочника?
   Через метод СоздатьГруппу():
   ```1c
   НоваяГруппа = Справочники.Номенклатура.СоздатьГруппу();
   НоваяГруппа.Наименование = "Новая папка";
   НоваяГруппа.Записать();
   ```
3. Как перенести элемент в другую группу?
   Заполнить свойство Родитель у объекта элемента и записать его.
4. Как изменить элемент по ссылке?
   Получить объект по ссылке через метод ПолучитьОбъект(), изменить поля и записать.
5. Как проверить принадлежность элемента группе?
   Проверить свойство Родитель у ссылки на элемент и, при необходимости, подниматься по иерархии.
6. Как скопировать существующий элемент?
   Получить объект элемента, методом Скопировать() создать новый объект, изменить код/наименование и записать.
7. Как заблокировать элемент перед изменениями?
   Использовать менеджер блокировки данных или управление блокировками в модуле объекта.
8. Как заполнить новый элемент на основании?
   Использовать механизм "Ввод на основании".
9. Как пометить на удаление элемент?
   Установить свойство ПометкаУдаления у объекта элемента в Истина и записать его.

📄 Документы

1. Как перебрать строки табличной части документа?
   Через коллекцию табличной части объекта документа:
   ```1c
   Для Каждого СтрокаТЧ Из ОбъектДокумента.Товары Цикл
       Сообщить(СтрокаТЧ.Номенклатура);
   КонецЦикла;
   ```
2. Как создать новый документ?
   Метод СоздатьДокумент() у менеджера документа:
   ```1c
   НовыйДок = Документы.РеализацияТоваровУслуг.СоздатьДокумент();
   ```
3. Как записать документ?
   Вызвать метод Записать(<РежимЗаписи>) у объекта документа.
4. Как провести документ?
   Вызвать метод Провести(), предварительно записав его.
5. Как отменить проведение документа?
   Установить свойство Проведен объекта в Ложь и записать его с режимом РежимЗаписиДокумента.ОтменаПроведения.
6. Как изменить документ по ссылке?
   Получить объект по ссылке через ПолучитьОбъект().
7. Как получить пустую ссылку типа документ?
   Через менеджер документа: Документы.РеализацияТоваровУслуг.ПустаяСсылка().
8. Как скопировать существующий документ?
   Получить объект документа и использовать метод Скопировать().
9. Как заблокировать документ перед изменениями?
   Использовать менеджер блокировки данных.
10. Как создать новый документ на основании другого объекта?
    Через метод СоздатьДокументНаОсновании(<ОбъектОснование>).
11. Как пометить на удаление документ?
    Установить свойство ПометкаУдаления объекта в Истина и записать его.

🗄️ Регистры

Регистры сведений

1. Как найти и изменить записи в регистр сведений?
   Использовать объект РегистрСведений.НаборЗаписей, установить отбор, прочитать, изменить коллекцию и записать.
2. Как создать записи без привязки к документу?
   Создать набор записей независимого регистра сведений, добавить записи и записать с режимом замещения Ложь.

Регистры накопления

1. Как найти и изменить записи регистра накопления документа?
   Использовать объект РегистрНакопления.НаборЗаписей, установить отбор по регистратору (документу), прочитать, изменить и записать.
2. Как создать записи без привязки к документу?
   Технически каждая запись в регистре накопления должна иметь регистратор. Без него записи создать невозможно.
