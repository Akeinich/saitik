Программирование в 1С.
Практическое задание № 8-9.
Синтаксис языка запросов.
1)	Создать документ РеализацияТоваровУслуг с реквизитами:
Организация типа СправочникСcылка.Организация;
Покупатель типа Справочник.Сcылка.Контрагенты;
и табличной частью Товары с реквизитами:
Номенклатура типа СправочникСсылка.Номенклатура;
Количество типа Число (длина 10, точность 3).
Сумма типа Число (длина 15, точность 2).
Используя СКД, вывести количество различных контрагентов и общее количество записей (с.43).
2)	В документе РеализацияТоваровУслуг вывести все документы, дата создания которых больше 01.08.2015 (c.44).
3)	Вывести список всех клиентов из документа РеализацияТоваровУслуг (с.41).
4)	Создать иерархический справочник Поставщики. Вывести в отчет все поля из справочника Поставщики (с.30).
5)	 Вывести всех поставщиков, в названии которых встречается ИП (c.47).
6)	Добавить в справочник реквизит Телефон. Вывести всех поставщиков, телефон которых соответствует шаблону “_-__-__” (c.48).
7)	Используя СКД, вывести  записи справочника «Номенклатура», расположенные в порядке иерархии. Если не указан производитель, в строке справочника вывести NULL (с.59).
8)	Вывести записи справочника «Номенклатура», не являющиеся группой (c.61). 
9)	Вывести минимальную, максимальную и среднюю цену товара из документов РеализацияТоваровУслуг. (c.69).
10)	Вывести общее количество единиц проданного товара (c.70).
11)	Отобрать товары, проданные на сумму более 1000 руб.	 по каждому покупателю (c.72).

При  выполнении задания использовать электронную книгу:
Хрусталева Е. Ю. Язык запросов «1С: Предприятие» – М.: 1C-Паблишинг, 2013.
